PFOTENPIXEL | Studienprojekt

START: ZIP entpacken, index.html im Browser öffnen. Ordnerstruktur unverändert lassen.
ABGABE: Alle Inhalte dieses Ordners auf einen statischen Hoster (z. B. GitHub Pages) laden. Link zur index.html und Link zur logbuch.pdf im Kurs-Tool abgeben. Bei GitHub Pages wird 404.html automatisch als Fehlerseite verwendet. Bei anderen Hostern ggf. konfigurieren. Lokal 404.html direkt öffnen.

Die Veranstaltung, die Halle, Namen und Preise sind fiktiv. Das Formular speichert und versendet nichts. Kein externer Dienst.

PRÜFSTAND: Quelltextprüfung: 341 Wörter Startseite, 1538 Wörter über alle sechs Hauptinhalte, 27 h2/h3, eine h1 je Seite. Alle relativen Links und Sprungziele vorhanden. Titel/Descriptions im geforderten Längenbereich. 12 unterschiedliche illustrative Rastermotive plus animiertes GIF, SVG-Logo und 3 SVG-Icons, alle Bilder unter 300 KB und max. 900 px breit. CSS enthält Media Queries für 375 px, reduzierte Bewegung und Druck; lokal erzeugte WOFF2-Stempelschrift. Startseiten-Vorschau gerendert. Direkte Navigation im Prüf-Browser war gesperrt, daher kein abgeschlossener End-to-End-Test. W3C, Lighthouse, Konsole, Netzwerk, Mobilansicht aller Seiten und Hosting-404 selbst prüfen. Für Social-Sharing nach Hosting og:image bei Bedarf auf die absolute öffentliche URL setzen.

logbuch.pdf ist ein Entwurf auf Basis des tatsächlichen Gesprächs. Bitte persönlich ergänzen (insbesondere die eigenen Prüfungen).
